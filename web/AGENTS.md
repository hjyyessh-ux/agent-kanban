# web

## Purpose
The React/Vite single-page application front end for agent-kanban. This directory is the web workspace root: it holds the Vite HTML entry point and the `src/` application tree. The dev server runs on port 5173 and proxies `/api` → `:24680`; production output is emitted to `dist/` and served statically by the Bun server.

## Key Files
| File | Description |
|------|-------------|
| `index.html` | Vite HTML entry point that mounts the SPA (loads `src/main.tsx`) |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `src/` | React SPA source — `App.tsx` owns tabs/modals, hooks do fetching/polling, plain CSS with `.neo-*` tokens (see `src/AGENTS.md`) |
| `dist/` | Build output (generated by `bun run build:web`) — do not edit by hand |

## For AI Agents

### Working In This Directory
- **fetch() lives in hooks, not components** (`src/hooks/`). Polling is the sync model (board 3s, others 10s).
- Import shared types from `../src/core/types.ts` — never redefine DTOs in the web layer.
- No React Router, Tailwind, CSS-in-JS, or React Query/SWR. Styling is plain CSS with `.neo-*` token classes.

### Testing Requirements
- `bun run dev` for the local dev server; `bun run build:web` to produce `dist/`.
- End-to-end coverage lives in the top-level `e2e/` Playwright suite (`bun run test:e2e`).

### Common Patterns
- `App.tsx` owns tab and modal state; feature components live under `src/components/<Feature>/` with a co-located `.css` file.

## Dependencies

### Internal
- `src/core/types.ts` — shared DTOs
- The Bun server (`src/server/`) serves `dist/` and backs the `/api` routes the SPA calls

### External
- React 18 + Vite
