#지금 (BEFORE의 노란 번호)바꾸는 방법
1Work가 테두리 상자 + WORK 탭 + ID상자 대신 제목 한 줄 + 아래 파란 선(섹션 헤더). 접기 ▾, 세션 수, 안 읽음 수만 보이고 ⋯(이름 변경·폐기·ID 복사)는 마우스를 올렸을 때만.
2세션도 상자 + SESSION 탭, 디렉토리·런타임·ID·카드 수가 각각 칩세션은 한 줄짜리 항목: 제목 / 최신 turn 요약(질문 → 답) / 디렉토리 · N턴 · 시각. 왼쪽 색 띠가 상태. 클릭하면 세션 모아보기.
3HIDE · 완료 · resume · W칩 · 정렬이 늘 보임세션 조작은 hover 때만 ⏎(resume 복사)와 ⋯(숨기기 · Work 이동 · 세션 완료). 완료는 Work 단위 하나만 늘 보이게 하고 위치는 Work 맨 아래.
—보드 안에 turn 타임라인이 펼쳐짐보드에서는 빼고 세션 모아보기에서만 봅니다. 보드 = 목록, 세션 모아보기 = 상세. 타임라인이 빠지면 칸 높이가 대략 1/4로 줄어듭니다.
—Work에 안 묶인 세션의 위치가 애매함컬럼 맨 아래 "WORK 없음" 묶음으로 모읍니다. Inbox 개념을 보드에서도 같은 말로.
  • 점진적 노출: 처음 설치하면 GROUP 기본값을 SESSION으로 두고, 첫 Work를 만들면 그때 WORKS로 바꿀지 한 번 묻습니다. Work를 모르는 사람은 Work를 볼 일이 없게.
  • 용어 통일: 화면에 "cards / turns / Feedback"이 섞여 있습니다(예: 26 cards, 모달은 16 turns). 보드 표면에서는 턴 하나로 통일하고 카드라는 말은 카드 상세 안에서만 씁니다.
  • 바꾸지 않는 것: Work 완료 시 일괄 archive, 드래그로 Work 배정, 상태색 규칙(--kv2-status-*)은 그대로 둡니다. 보이는 방식만 바꿉니다.
