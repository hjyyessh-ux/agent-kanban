③ 변경 포인트 · 근거 (design critique)

P0목록을 "주의 필요" 우선으로 묶기

예정 초과·N일 무활동·실행 중 Work를 맨 위 그룹으로. 지금은 이 신호가 최근 활동순 정렬 때문에 항상 맨 아래로 가라앉는다. "디렉토리별" 묶기도 토글로.

P0목록 = 타임라인 (strip 통합)

별도 strip(첫 화면 1/4) 대신 각 행에 14일 활동 히트맵을 공통 날짜축에 맞춰 붙인다. 12개 전부가 한 화면에 들어오고 "언제 움직였나"를 행에서 바로 읽는다. 날짜 드래그 편집은 "전체 타임라인 ↗"에 남긴다.

P0행 액션 정리 · 행 높이 절반

`상세` 버튼 제거(행 클릭 = 상세), `완료…`는 hover/포커스 시에만 + 키보드 `c`. 모든 행이 같던 파란 스트라이프는 "주의 필요" 행에만 주황으로. 행 높이 ~80px → ~48px.

P1행 2줄째 = 최근 결과 / Summary

숫자 나열(진행 0 · 완료 25) 대신 Summary 첫 줄, 없으면 마지막 카드 결과 한 줄. 숫자는 오른쪽 진행 바로. 기존 Summary 한 줄 표시는 이미 있으나 대부분 비어 있어 안 보임.

P1빈 상태는 한 줄

미배정 0이면 노란 박스 대신 "📥 미배정 0 ✓ 모두 정리됨" 한 줄. 세션이 들어오면 지금처럼 펼친다.

P0상세: 폼 → 사실 칩

디렉토리 박스·날짜 입력 3칸을 한 줄 칩(`agent-kanban` · 시작 10/21 · ＋ 예정일 · 최근 활동)으로. 클릭하면 기존 편집기(DirectoryPicker, date input)가 열린다. 첫 화면 ~170px 회수.

P1상세: 진행을 그림으로

KPI 4칸(세션·끝난 카드·남은 카드·완료 가능 여부)과 세션 흐름 레인(어느 세션이 언제 돌았나). "완료해도 되나?"에 숫자 해석 없이 답한다.

P1세션 행에 마지막 결과 + ↩ 이어서

세션별 마지막 turn 결과 한 줄 → 열지 않고 상태 파악. hover 시 `↩ 이어서`(그 세션에 피드백 카드 생성)로 Work 화면에서 바로 다음 작업.

P0상세: 위험 동작 위계

폐기·삭제·병합을 `관리 ▾` 메뉴로, 삭제는 메뉴 맨 아래 빨간 글자 + 설명. 푸터에서 눈에 띄는 건 `✔ 완료` 하나. 초록 안내 배너는 버튼 옆 한 줄 힌트로.

P2숨은 기능 드러내기

기존 제목 클릭 편집에 ✎ 어포던스, 기존 완료 미리보기 숫자를 버튼 옆 힌트로 상시 노출. 기능 추가 없이 발견성만 올린다.
