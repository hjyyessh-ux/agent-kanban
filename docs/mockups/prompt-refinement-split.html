변경 제안읽고 넣거나 빼기, 필요하면 편집기존 suggestion, 기본 틀의 “(제안)” 섹션넣기
원문 유지원문에서 그대로 인용한 제약 — 보통 손댈 필요 없음기존 extracted, 금지 문장 인용넣기
  • 구역(목적 · 조사 조건 · 완료 조건 · 검증 · 제약)은 오른쪽 그룹 제목. AI 응답에는 구역 필드(slot)를 추가하고, 기본 틀은 현재 섹션 id를 구역에 고정 매핑.
  • 원문 하이라이트: 원문 발췌/확인 필요 카드가 가리키는 원문 구절을 왼쪽에 표시(발췌는 원문에 정확히 존재하는 문자열만 — 기존 검증 규칙 유지).
  • 본문에 넣기 / 빼기는 지금의 체크박스 선택을 대체. 편집 내용·넣기/빼기·결정 값은 세션에 보존되어 창을 닫아도(×, Esc) 원문이 같으면 복원 — 이번 변경에서 이미 구현(바깥 클릭 무시, 크기 저장, “새로 시작”).
  • 적용은 원문 뒤에 넣기로 고른 섹션만 추가(기존 applyPromptPreview 규칙). 원문 자체를 고치는 기능은 범위 밖 — 원문 수정은 기존 입력칸에서.
  • 모델 칩: 이번 생성에만 적용, 기본값은 설정 › 다듬기 모델. 변경 시 결과는 ‘다시 생성’ 전까지 유지하고 “다른 모델로 만든 결과” 표시.
