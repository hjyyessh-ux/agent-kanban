MOCKUP 대기(TODO) 카드 Work 지정 화면:
상세 배치:
테마:
태그·⋯·WORK 칸을 눌러 지정 / 변경 / 해제 · ▶ 시작으로 예약 → 연결 전환

핵심: "예약" 과 "연결" 두 상태

  • Work는 세션을 묶습니다. 대기 카드는 아직 세션이 없어 지금은 넣을 방법이 없습니다(드래그해도 "세션이 없는 카드는 Work에 넣을 수 없습니다").
  • 예약 = 카드에 Work를 미리 적어 둠(card.plannedWorkId). 점선 태그 WSMS Whitelist 관리예약
  • ▶ 시작으로 세션이 생기는 순간 서버가 그 세션을 Work에 연결하고 예약을 지웁니다 → 실선 태그 WSMS Whitelist 관리
  • 이미 세션이 있는 대기 카드(피드백·resume)는 예약 없이 바로 연결합니다 — 지금 드래그·트레이가 하는 일과 같은 API.
  • Work 미배정 · 드래그해서 넣기 안내는 뺍니다. Work가 없으면 줄 자체가 없고, 지정은 ⋯에서.

예외 규칙

  • 예약한 Work가 시작 전에 완료·삭제·병합됨 → 병합이면 병합 대상으로 따라가고, 완료·삭제면 예약을 지우고 카드에 ⚠ 예약한 Work가 닫혀 연결하지 않았습니다 한 줄 (다음 지정 때 사라짐).
  • 큐로 직전 세션을 이어붙이는 카드는 앞 카드의 세션을 쓰므로 Work도 앞 카드를 따릅니다 → 피커 대신 안내만: "앞 카드 세션을 이어 써서 그 Work를 따릅니다".
  • 세션이 이미 다른 Work에 있는 카드(피드백 등)에서 다른 Work를 고르면 = 세션 이동 (기존 moveSession), 되돌리기 제공.
  • 예약은 Work 목록·Timeline에는 나오지 않습니다(세션이 없으니까). Work 상세에 "예약된 대기 카드 N" 정도만 후속으로 검토.
  • 카드를 지우면 예약도 같이 사라집니다.
