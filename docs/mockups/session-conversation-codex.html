P0 / 읽기 순서

가장 자주 찾는 결과가 가장 멀다

compareOldestCardFirst로 고정 정렬하고 첫 턴부터 엽니다. 기본을 6 → 1로 바꾸고 시간순도 제공합니다. 번호는 생성 순서대로 유지하며 최신 표시와 피드백 대상은 정렬에서 독립시킵니다.

P0 / 정보 위계

번호보다 작업 내용이 먼저

큰 Turn pill·중첩 테두리·반복되는 날짜가 경쟁합니다. 작은 번호 → 카드 제목 → 결과 첫 줄 순으로 재배치합니다. 최신 결과만 펼치고 Prompt는 한 줄 미리보기로 접습니다. 서브에이전트의 기존 기본 접힘은 유지합니다.

P1 / 색과 대비

분홍은 넓은 면보다 작은 신호로

기존 분홍 Turn 라벨의 흰 글자는 약 3.45:1로 일반 텍스트 AA 4.5:1에 못 미칩니다. 제안은 테마별 잉크를 사용하고 분홍은 검토 대기 배지와 Result의 가는 선에 둡니다. 최신은 중립 라벨로 구분합니다.

P1 / 탐색과 회수

숫자만으로는 돌아갈 곳을 모른다

기존 숫자 칩은 제목을 hover tooltip에만 담습니다. 제목이 보이는 턴 바로가기와 항상 접근 가능한 최신 턴 이동을 제공합니다. 본문 검색은 일치한 턴만 표시하고 숨겨진 Prompt·서브에이전트도 펼칩니다. 전체 결과를 복사해 다른 작업에 재사용할 수 있습니다.

P1 / 키보드·접근성

탭처럼 보이지만 탭이 아닌 탐색

기존 칩은 tablist/tab이지만 연결된 tabpanel과 방향키 이동이 없습니다. 실제 역할에 맞는 버튼·select로 바꿉니다. 반복되는 show/hide에는 턴별 접근성 이름을 주고, 포커스 링·검색 결과 알림·줄어든 모션을 지원합니다.

P2 / 후속 작업

상시 입력창 대신 명확한 이어쓰기

큰 피드백 dock이 읽기 영역을 줄이고, 어느 턴에 붙는지 말하지 않습니다. 기본은 작은 이어쓰기 바, 클릭하면 초안을 펼칩니다. 과거 Turn 2를 읽어도 대상은 최신 완료 Turn 6임을 표시합니다. 정렬·검색을 바꿔도 초안은 유지합니다.

인터랙션과 구현 경계

  • 최신순 초기 상태: Turn 6 Result만 노출합니다. 모두 펼치기는 턴 본문을 열고, Prompt·서브에이전트의 개별 접힘은 유지합니다. 모두 접기는 턴을 닫습니다.
  • 정렬: 생성 순서로 번호를 붙인 뒤 표시 순서만 뒤집습니다. 정렬 변경 시 목록 맨 위로 이동하며, 펼침과 초안은 유지합니다. 실제 카드 식별자는 그대로입니다.
  • 검색: 대소문자를 구분하지 않는 문자열 검색입니다. 결과 수는 일치한 턴 수입니다. 제목·원문 첫 줄을 사용하므로 별도 AI 요약은 필요 없습니다. 검색 해제 시 기존 펼침 상태로 돌아갑니다.
  • 최신 턴으로: 검색 중이면 필터를 해제한 뒤 Turn 6을 펼치고 이동합니다. 선택한 정렬은 유지합니다. 결과 복사는 화면 요약이 아닌 전체 Result를 복사합니다.
  • 실제 앱 적용 시: 기존 DialogSkeleton·IdChip·ResumeCopyButton·CardMarkdown을 재사용합니다. 기존 포커스 트랩과 Esc는 유지하고 세션 제목을 dialog의 접근성 이름에 연결합니다. 현재는 title prop이 없어 이름이 “Dialog”입니다.
  • 목업 범위: 같은 6개 턴으로 비교한 정적 HTML입니다. 실제 API·세션 실행·파일 첨부는 연결하지 않습니다. 확대 보기만 브라우저 기본 dialog로 접근성을 시연합니다.
