변경 포인트 · 근거 (design critique 기반)

P0최신순 기본 + 정렬 토글

최신 turn이 맨 위. Turn 번호는 시간순 그대로(T6 = 최신) 유지해 정렬을 바꿔도 "몇 번째"가 흔들리지 않음. 선택은 localStorage 기억. — 실제 코드에 이미 반영.

P0Result 우선, Prompt는 3줄 프리뷰

사용자가 모달을 여는 목적은 "결과 확인"이다. 긴 지시문은 페이드 프리뷰로 줄이고 클릭 시 전체. 이전 turn은 헤더 1줄(요약·소요시간)로 접힘 → 16 turn도 한 화면에 개요.

P1숫자 칩 → 좌측 목차(outline)

번호만 있던 칩을 "T번호 · 카드 제목 · 소요시간 바"로. 어떤 turn이 오래 걸렸는지, 어디로 갈지 바로 판단. 좁은 폭에선 ☰로 숨김.

P1핑크는 "신호"에만

turn 카드 면을 중립(surface)으로 되돌리고, complete 핑크는 최신 turn의 좌측 바 · LATEST 태그 · 다이얼로그 스트라이프에만. 제목(20px/800)이 turn 라벨(12px mono)보다 확실히 위.

P1세션 내 검색

prompt/result 전문 검색, 매칭 turn만 남기고 하이라이트 + 목차에도 표시. "그때 그 에러 어느 turn이었지"를 스크롤 없이.

P2Result 액션 · 키보드

Result 복사 / Markdown 복사 / 카드 열기. j/k·o·/·e·c 단축키. 스크롤이 내려가면 "↑ 최신 turn으로" 플로팅 버튼.

P2피드백 독 축소 + 대상 명시

평소 1줄, 포커스 시 확장 → 읽기 공간 +~90px. 어느 turn(카드)에 이어붙는지 명시해 오해 방지. ⌘↵ 전송.
